# Implementação do Teste Técnico

## Autor

Daniel Augusto

## Sobre o projeto

Este projeto foi desenvolvido como parte de um teste técnico de frontend.

A estrutura original foi mantida, seguindo os padrões já existentes nos módulos de Clientes e Usuários.

## Funcionalidades implementadas

### Veículos

* Cadastro de veículos;
* Edição;
* Exclusão;
* Listagem;
* Busca;
* Filtros;
* Paginação;
* Visualização de detalhes;
* Ações em lote;
* Exportação para CSV;
* Histórico de alterações;
* Validação de placa duplicada;
* Associação com empresas já cadastradas.

### Dashboard

* Total de clientes;
* Total de usuários;
* Total de veículos;
* Indicadores de status;
* Filtros;
* Veículos recentes;
* Paginação;
* Atalhos para os módulos.

## Como executar

Pré-requisitos:

* Node.js 20 ou superior;
* npm.

Instale as dependências:

```bash
npm install
```

Inicie o projeto:

```bash
npm run dev
```

Acesse:

```text
http://localhost:3000
```

## Login

O login é mockado. Qualquer usuário e senha funcionam.

Exemplo:

```text
Usuário: demo
Senha: demo123
```

## Testes

Para executar os testes:


```bash
npm test
```
